# 四路 PWM 输出

`interface.hpp` 定义平台无关 `IPwm`、四路绝对脉宽（µs）和操作错误。
`k230/output.cpp` 包含厂商头文件并调用 HAL；L4 仅通过板级工厂取得接口。
构建目标为 `dart_pwm`，交叉构建随相机默认启用 `DART_PWM_K230`。

通道和引脚沿用 `tools/pwm_swing`：CH1～4 对应 PWM1/2/3/5、IO61/7/8/59。
初始化先停用全部输出，再配置并读回引脚路由（保持 MSC 电压选择），设置两个共享周期组为
333 Hz，写入四路独立初始脉宽后逐路使能，并核对频率/脉宽读回。
每次写入前校验整组脉宽；部分写入、路由或读回失败均尝试关闭全部通道并释放 HAL。
`stop()` 幂等，某路关闭失败仍继续处理其它路。

`session.cpp` 的 `Session` 管理独立 pthread，每 10 ms 检查最新发布值，
仅有变化时调用设备写入。超过配置时限未收到有效目标，或显式发布无目标，输出回到
各路初始位置。发布和统计使用互斥锁；厂商调用和日志不在锁内。
写入失败后任务关闭设备，不反复重试。`stop()` 等待任务退出，之后设备即可析构。
任务不访问图像、IMU、录像或文件日志，因此暂停写文件不影响超时处理。

同一进程只能有一个 HAL 所有者，不能与 `pwm_swing` 或其它进程同时占用这些 PWM。
关闭波形表示停用 PWM；不保证舵机断电或机械回到零位。

主机 `pwm_output` 模拟 HAL 验证路由、初始化顺序、µs→ns 转换、读回和失败清理；
`visual_servo` 验证视觉选择/映射、丢失与超时、写入故障；`binary_pipeline` 覆盖真实检测器
到 PWM 的完整链路及输出失败时录像继续。真实波形和机械方向需要板端验证。
